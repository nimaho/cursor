# پروژه ساده Bootstrap 5 (RTL)

این پروژه یک صفحه‌ی ساده و آماده با **Bootstrap 5** (نسخه‌ی 5.3.x) است و برای صفحات فارسی **RTL** تنظیم شده.

## اجرا

- **ساده‌ترین راه**: فایل `index.html` را مستقیم در مرورگر باز کنید.
- **پیشنهادی**: با یک سرور محلی اجرا کنید تا همه چیز مشابه محیط واقعی باشد.

مثال با پایتون:

```bash
python3 -m http.server 5173
```

سپس در مرورگر باز کنید:

- `http://localhost:5173`

## ساختار

- `index.html`: صفحه اصلی
- `assets/css/styles.css`: استایل‌های سفارشی کوچک
- `assets/js/main.js`: تغییر حالت روشن/تیره + رفتار نمایشی فرم
